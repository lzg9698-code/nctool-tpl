    关于 nctool Web UI
    
    
    
      
    
        
    定位
    本地运行的模板参数表单 + 实时 G-code 预览（docs/DEV_PLAN_CLI_UI.md §5/§6）
    
        
    形态
    单文件 index.html，零外部依赖；可经 include_str! 内嵌进 binary
    
        
    演示模式
    内置模板库 + 迷你 Jinja 渲染器 + 客户端校验/后处理，离线完整可用
    
        
    服务模式
    将 JS 中 API.mode 改为 'server' 并设置 base，
          全部请求转至 nctool ui 的 HTTP 接口（{ ok, data?, error? }）
    
        
    界面设计
    v2 设计方案见 docs/UI_DESIGN_PROPOSAL.html：结果优先 · 就地反馈 · 渐进披露 · 状态可见；
          快捷键 ⌘/Ctrl+K 命令面板、⌘/Ctrl+⏎ 立即生成、⌘/Ctrl+S 存为预设
    
        
    功能覆盖
    模板浏览/搜索/分类 · 参数表单自动生成（必填进度 + 就地校验）· 实时预览 ·
          生成选项（行号/头部/ASCII/空行/宽松）· 工序索引 · 复制/下载 · 机床切换 · 参数预设 · 批量生成 · 主题切换
    
        
    渲染口径
    与 nctool-core 管线一致：校验 → 规格默认值兜底 → machine 注入 → 后处理
    
      
    
    
    
    
    
  
    

    



    
  
  
    

    


    






    
  
    
    
    自定义机床配置
    
    
    
      
    
        
      
    
      
    config 键值均为字符串，模板通过 {{ machine.xxx }} 引用；
        保存后在下拉框选择「自定义」即可生效（localStorage 持久化）。
