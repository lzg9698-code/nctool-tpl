# 当前路线图

更新日期：2026-10-24。当前主线范围为通用模板、共享参数、通用插件和独立 math 扩展；内置 NC 已移除。两轮底座完善已随 v2.3.0 发布，能力与实际验证统一见[项目状态](PROJECT_STATUS.md)。

## 当前待办与交付边界

已交付的两轮底座完善不再列为待办。契约与诊断、插件作者验收、执行追溯、调用元数据、历史维护与资源缓存的说明分别见[宿主契约](CONTRACTS.md)、[插件验收](PLUGIN_ACCEPTANCE.md)和[运行维护](OPERATIONS.md)。

- v2.3.0 的三平台、MSRV、依赖审计、构建和发布证据已取得；只覆盖对应标签提交，不能替代后续修改的验证。
- 后续改动按受影响范围重新验证，发布按[发布说明](RELEASE.md)执行完整门槛、联网审计和产物签收。路线图不自动授权提交、推送、打标签或发布。

## 待讨论：工艺与数控编程外部插件

[插件扩展提案](MACHINING_PLUGINS_PLAN_2026-10-24.md)列出切削工时、坐标几何、工艺文档、尺寸余量、NC 静态检查和程序片段六类候选；建议首批只试点切削与坐标计算。该顺序与功能范围尚未确认，不代表已授权实施，也不属于当前发行能力。

下一步待收敛高频任务、车铣占比、主要控制系统、脱敏算例及部署方式，再明确首批动作与验收。加工实现保持为独立外部插件，不恢复宿主内置 NC 或旧加工动作。

## 已规划：以 FTU 接入扩展通用插件底座

用户已明确底座需具备相关能力，FTU 无须照抄，可换技术栈复现。当前方向为原生通用工程工作台：编辑表格、二维场景/播放、项目/草稿和预览执行底座；建议沿用 React/Ant Design，以独立 Rust 外部插件重实现 FTU 业务。此前 iframe + Node 代码适配路线已被替代。

阶段与验收方向见[新版实施计划](ENGINEERING_WORKBENCH_PLAN.md)。当前工作树已实现原生工作台、项目/预览闭环和独立 Rust FTU，NC 由 Jinja 模板生成并经后处理校验；使用与实际契约见[工程工作台](ENGINEERING_WORKBENCH.md)。新增功能尚未发布，原正式版和历史测试不替代本轮验收。

继续按实际使用数据维护可靠性与规模。当前没有新增数据库、游标格式或压缩运行时的迁移承诺；若以后测量显示需要，再按问题立项。插件市场、通用 DAG、云同步与框架重写暂不进入主线。
