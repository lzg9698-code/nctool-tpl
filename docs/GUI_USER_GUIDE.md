# 桌面 GUI 使用说明

桌面端位于 `gui/`，由 Tauri 2 与 React 构成。开发运行方式见 `gui/README.md`；本页记录当前页面能力与写入行为。

## 页面

- **渲染**：选择模板、编辑参数并预览 NC 输出；可保存输出文件。选中 `unreviewed` 模板时会显示工艺复核与空运行警告。
- **模板管理**：浏览模板评审状态与参数规格；支持创建文件模板、编辑文件模板、从现有模板派生和重命名。内置模板只读。
- **检查**：执行模板参数校验与静态 lint。
- **机床配置**：查看内置/自定义机床，根据配置 schema 编辑或新增自定义机床，并删除自定义项；内置机床只读。
- **参数预设**：管理参数预设并将其应用到渲染页。
- **设置**：查看全局与项目配置来源、生效的模板目录/默认机床、自定义机床及配置加载警告。

## 文件写入与冲突

模板、机床和预设的操作通过与 Web UI 共用的 `nctool_cli::server::route` 执行，再由
`nctool-core` 资产写入接口落盘；写入采用原子替换、路径约束和文件指纹乐观锁。若文件在读取后被
外部修改，保存会报告冲突，刷新后再编辑即可。内置模板和机床不能覆盖。

GUI 当前的设置页用于诊断和查看，不直接编辑 `nctool.toml`；配置仍可按 [机床配置指南](MACHINE_CONFIG_GUIDE.md) 手动维护。保存模板、机床和预设前建议备份项目配置及资产。

## 验证边界

本说明描述源码已实现的交互，不代表所有操作均完成桌面环境人工验收。NC 输出投产前仍须由工艺人员核对并在目标机床空运行，参见 [工艺核对清单](PROCESS_CHECKLIST.md)。
