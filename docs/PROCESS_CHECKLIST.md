# 工艺核对清单（内置模板 × 机床预设）

> 版本：v1.0 · 2026-09-03 · 阶段 A1
> 目的：逐行核对内置模板输出的 G/M 代码正确性与工艺安全约定；为将来的
> **外部工艺评审**提供逐条勾选的载体。
>
> ⚠️ **评审级别说明**：本清单为 **AI/代码级自动核对**（G-code 常识标准 +
> 与 golden 基线逐字节比对），**不是**真实工艺工程师评审，也不是机床手册
> 核验。项目当前无工艺评审资源（ROADMAP Q2 = 否），按降级预案执行：
> 项目定位为**模板开发工具**，投产前必须由熟悉目标机床的工艺人员
> 逐行核对并空运行验证（见 README 显著声明）。

## 0. 核对范围与方法

- 对象：5 个内置模板（`program_header` / `program_footer` / `tool_change` /
  `safe_move` / `drill_cycle`）× 3 个机床预设（`generic` / `wfl_m65` /
  `index_ms40`），输出见 `tests/golden/*.nc`（15 组基线）。
- 方法：逐行对照 golden 输出，按 G/M 码模态组、字址合法性、循环取消、
  坐标系初始化、工艺安全五类标准核对。
- 结论标记：✅ 已核对（符合通用标准）/ ⚠️ 约定或差异（需用户或手册确认）/
  ❌ 未通过（立即修复）。

## 1. program_header（程序头）

golden（generic）：

```nc
%
O0001
( DEMO )
(  )
G21 (metric)
G90 G17 (绝对坐标 / XY 平面)
G40 G49 G80 (取消刀补 / 刀长补偿 / 固定循环)
G54
G94
M5
M9
```

| 行 | 内容 | 结论 | 说明 |
| --- | --- | --- | --- |
| 1 | `%` | ✅ | 纸带起始符（FANUC 系惯例）；上传到部分控制器时不发送。约定由 `program_prefix` 之外的用户侧处理 |
| 2 | `O0001` | ✅ | 程序号：FANUC `O` + 前导零 4 位（`program_prefix` / `program_digits` 键接线）。⚠️ Mazak 等用 `P` 或 `%` 体系，经 `program_prefix` 可配 |
| 3-4 | `( DEMO )` `(  )` | ✅ | 注释行（零件名/工序名可空），无字址影响 |
| 5 | `G21 (metric)` | ✅ | 单位制声明：`machine.units=imperial` → `G20`，否则 `G21`；模态组 01 与坐标无关 |
| 6 | `G90 G17` | ✅ | 绝对坐标 + XY 平面。⚠️ 车床（XZ 平面）用户须改用车削专用模板或改平面 |
| 7 | `G40 G49 G80` | ⚠️ | 取消刀补 / 刀长补偿 / 循环，均为"初始化清态"的正确选择。**G49 在部分控制器（如某些 Mazak/车铣复合）需用 `G43 H0` 等价表达**，generic 按 FANUC 约定 |
| 8 | `G54` | ✅ | 第一个工件坐标系（`coordinate_system` 键，默认 G54；G55-G59 可配） |
| 9 | `G94` | ✅ | 每分进给（`feed_mode` 键；G95 每转进给可配，车削常用） |
| 10-11 | `M5 M9` | ✅ | 程序起始确保主轴停 + 冷却关，双重安全 |

## 3. tool_change（换刀）

```nc
M5
M9
M6 T5
G40 (取消刀补)
G43 H5 (刀长补偿)
M3 S3000 (主轴正转)
M8 (冷却开)
```

| 行 | 内容 | 结论 | 说明 |
| --- | --- | --- | --- |
| 1-2 | `M5 M9` | ✅ | 换刀前主轴停、冷却关 |
| 3 | `M6 T5` | ✅ | 换刀同块写法（FANUC 标准单形式）。⚠️ 部分机床习惯 `T<#>` 预选 + 后续 `M6`，或 ATC 库位与 T 号不同映像 → 按机床手册 |
| 4 | `G40` | ✅ | 取消刀补，防止上一道补偿残留 |
| 5 | `G43 H5` | ⚠️ | 刀长补偿：H 号 = 刀具号（工艺惯例 `H# = T#`）。**非所有机床**（部分用 H100+ 独立体系）；刀具号 spec 上限 999 → H 号同范围 |
| 6 | `M3 S3000` | ⚠️ | 主轴正转 + 转速（`spindle_on` 键可配 M13/M4 等）。**发现项 F1**：转速上界由模板规格硬编码 6000，与机床预设 `max_spindle_rpm`（WFL 3500 / INDEX 5000）**不联动**——用户配 WFL 时须人工保证 S ≤ 3500 |
| 7 | `M8` | ✅ | 冷却开（标准 M8；M12/M14 等经 `coolant_on` 可配） |

## 4. safe_move（安全移动）

```nc
G0 G90 Z100.000
G0 X10.000 Y20.000
```

| 行 | 内容 | 结论 | 说明 |
| --- | --- | --- | --- |
| 1 | `G0 G90 Z100.000` | ✅ | 快速抬刀到绝对安全高度（`safe_z` 默认 100，spec `min=0`） |
| 2 | `G0 X... Y...` | ✅ | 停在 XY 目标位；Z 保持安全高度 |
| 注 | 先 Z 后 XY | ✅ | 先抬刀避障再水平移动，方向正确。⚠️ `safe_z=100` 是开发示例值，生产须按毛坯/夹具最高点确认（spec 无上界属有意为之：上界取决于具体机床行程） |

## 5. drill_cycle（G81 钻孔循环）

```nc
G0 X21.000 Y15.000
G98 G81 R5.000 Z-10.000 F100.000
G80 (取消循环)
```

| 行 | 内容 | 结论 | 说明 |
| --- | --- | --- | --- |
| 1 | `G0 X21.000 Y15.000` | ✅ | 快速定位到孔位（模态 01 = G0；行 2 直接切换 G81 合法） |
| 2 | `G98 G81 R5.000 Z-10.000 F100.000` | ✅ | 循环块**不带 G1 前缀正确**：G1 与 G81 同属模态组 01，前缀冗余且部分控制器同组同块敏感。**发现项 F2**：`G98` 返回**初始平面** = 循环开始时 Z 高度——本模板不保证 Z 已抬至安全高度，使用约定：**先 `safe_move` 再把 `drill_cycle` 接在其后**（此时初始平面即 safe_z，循环结束后停回安全高度，正确且安全） |
| 3 | `G80` | ✅ | 循环取消，无残留 |
| 注 | 参数约束 | ✅ | `depth ≤ 0`（spec max=0，往 -Z 切削）；`feed > 0`（spec min=0.001）；`r_plane` 默认 5.000 应高于工件表面（spec min=0） |

## 6. 机床预设

| 预设 | 键覆盖 | 结论 | 说明 |
| --- | --- | --- | --- |
| `generic` | 17+3 键，FANUC 风格 | ✅ | 作为开发测试基线合理（O 前缀 / G54 / G94 / M30） |
| `wfl_m65` | 仅覆盖 `max_spindle_rpm=3500`、`machine_type`、`axes` | ⚠️ | **发现项 F3**：编程约定全部继承 generic（O 前缀/G54/M30…），未体现 WFL 车铣复合真实约定 |
| `index_ms40` | 仅覆盖 `max_spindle_rpm=5000`、`machine_type`、`axes` | ⚠️ | 同 F3：双主轴车铣复合的程序头/换刀约定未体现 |

> F3 处置：文档声明预设“仅供开发测试”（machine.rs 模块注释已有，README 亦将声明）；
> 三机床 golden 输出当前逐字节一致正是该现状的固化——当预设差异落地时，golden 立即暴露破坏。
> **按机床手册补齐预设键**列为外部评审必办项（Backlog）。

## 7. 发现项汇总与处置

| # | 发现 | 级别 | 处置 |
| --- | --- | --- | --- |
| F1 | 主轴转速上界 6000 为模板规格硬编码，机床预设 `max_spindle_rpm`（WFL 3500/INDEX 5000）不参与校验 | ❗ 工艺风险 | 本项目**不阻断**（用户自检）；已在本清单 + README 声明；Backlog：按机床校验参数（规格改为引用 `machine.max_spindle_rpm` 动态上界） |
| F2 | `drill_cycle` 的 G98 初始平面依赖调用前 Z 高度 | ⚠️ 使用约定 | 模板注释已注明；本清单 + README 声明使用顺序（safe_move → drill_cycle）；Backlog：提供组合模板“钻孔工序”（safe_move+drill）并冻结 golden |
| F3 | 机床预设未体现真实机床差异 | ⚠️ 待外部 | 声明“仅供开发测试”；外部工艺流程评审优先项 |
| F4 | G49（vs G43 H0）与 H#=T# 主张是 FANUC 惯例 | ⚠️ 控制器差异 | generic 按 FANUC 约定实现；其他控制器经 `coordinate_system`/`program_prefix` 等键可配，G49/H 映像不可配（Backlog：增加机键） |
| F5 | `safe_z` 默认 100 无上界 | ℹ️ 说明 | 上界应由机床行程决定，不宜静态设限；注释说明即可 |

**结论**：自动核对未发现需立即修复的 G/M 码错误（P0×0）。全部剩余项为
**文档化约定 + 外部手册/工艺核对**，已按降级预案在 README 显著声明。
