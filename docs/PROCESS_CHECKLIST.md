# NC 资产与工艺核对清单

适用于当前 NC 插件和多工序生成。当前发行包不包含旧业务模板或内置机床方案；清单针对使用者自己的模板、机床配置和实际输出。软件校验与回归测试不构成控制器或工艺签收。

## 核对记录

每次核对记录以下信息，结论区分“软件行为验证”“工艺复核”和“设备验证”：

- 模板稳定 ID、源码/引用版本与参数输入；临时源码保留当次内容。
- 机床资产 ID、指纹、厂商/型号、实际控制器及所依据的手册版本。
- NCtool 宿主与插件版本、服务绑定、生成选项、生成时间及最终输出文件。
- 复核人员、复核日期、未解决问题与结论；未经执行的项目保持未勾选。

## 模板与参数

- [ ] 生成方式为所需 NC 动作，所需插件与服务已启用。
- [ ] Schema 和 specs 的类型、范围、枚举、默认值、派生与条件分支已核对。
- [ ] 程序号、刀具号等使用整数，单位与模板计算一致；unit 提示不会自动换算。
- [ ] 模板引用与实际执行分支完整，必需机床字段存在；动态引用已用代表性输入验证。
- [ ] 缺参、错误类型、边界值及错误 JSON 不产生当前可交付程序。

## 目标机床与控制器

- [ ] 使用经过核对的目标机床 JSON 资产，未把虚拟默认机床视作目标设备。
- [ ] 核对单位制、坐标系、绝对/增量模式、轴方向、刀具与补偿约定。
- [ ] 根据目标手册核对程序号、行号、主轴、进给、冷却及相关 G/M 码。
- [ ] 机床动态上界与静态回退范围已核对，所有警告已处置。
- [ ] 配置的每个关键字符串与实际控制器约定一致，未以“保存成功”代替确认。

## 最终程序与多工序

- [ ] 核对经过后处理的完整正文，包括小数位、符号、空白、ASCII 替换和头注释。
- [ ] 检查行号上限/溢出警告、已有行号与程序号行，确认编号满足控制器要求。
- [ ] 检查工序顺序、公共参数及各工序覆盖，连续行号和跨工序状态符合预期。
- [ ] 任一工序失败时无整体产物交付；成功工序输出未被单独当作最终成品。
- [ ] 核对进入/退出位置、刀具与补偿状态、退刀和程序结束；清单不替代逐行工艺复核。

## 签收与复验

由熟悉目标机床的工艺人员复核，设备验证按现场流程完成并记录实际结果。模板、引用、参数规格、机床配置或生成选项变化后重新评估相关项目；跨版本历史重执行应核对环境差异及重新生成的程序。

操作说明见[机床配置](MACHINE_CONFIG_GUIDE.md)和[模板编写](TEMPLATE_WRITING_GUIDE.md)。旧版“内置模板 × 机床预设”记录保留在[历史清单](archive/legacy/PROCESS_CHECKLIST.md)，其勾选结果不能用于当前资产。
