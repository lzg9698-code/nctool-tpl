# 模板参数

参数由每个模板自己管理，沿用模板资产的 `schema` 与 `defaults`：

- `schema` 描述参数名、类型和必填等约束；
- `defaults` 保存打开使用任务时预填的值；
- 本次填写保存在工作台文档的 `context`，不会改写模板默认值。

编辑模板时，右侧“参数”区直接编辑每个参数的名称、类型和默认值；必填、说明、单位、范围和候选值等放在该参数的“高级”中。使用模板时只显示参数表单，“恢复默认值”把表单恢复为模板默认值。

```json
{"source":"深度 {{ part.depth }} mm","schema":{"type":"object","properties":{"part":{"type":"object","properties":{"depth":{"type":"number","minimum":0}}}}},"defaults":{"part":{"depth":6}}}
```

渲染使用普通 `template.render`：`context` 覆盖同名的顶层默认值，未填写的参数使用 `defaults`。默认值缺省、空字符串、`null`、`false` 与 `0` 是不同值；数值保留精确字面量，非有限数、越界整数和未完成草稿会被拒绝。

模板历史记录保存源码集合快照和当时的输入，重执行不改写原记录。重复填写可继续依赖浏览器草稿恢复；需要改变以后打开模板时的初始值，直接修改模板默认值。
