# WebUI 验收清单

适用于 NCtool 2.2 工作台。以下是待执行清单，不沿用旧版 37/37 通过结论。操作说明见[WebUI 指南](WEBUI_USER_GUIDE.md)，自动检查见[贡献指南](CONTRIBUTING.md)。

## 准备与记录

记录日期、平台、浏览器/版本、源码提交及未提交改动、CLI/插件版本、构建组合、实际执行项和证据路径。使用独立临时 home/workspace，按快速开始生成资源并编译宿主；分别启动 template 和 nc 组合，默认地址 `http://127.0.0.1:8788`。

准备一个含对象、数组、数值、布尔和默认值的普通模板，一个具有 Schema、specs、机床字段的 NC 模板，以及可被引用的共享模板；可参考[模板编写指南](TEMPLATE_WRITING_GUIDE.md)和[现有示例](../examples/v2)。不使用用户的实际机床或生产资产。

## 通用模板工作台

- [ ] 默认 template 组合只有通用能力，无机床/工序导航；NC 声明存在但能力缺失时阻止领域生成。
- [ ] 新建、导入 `.j2` / JSON、搜索、打开多文档、复制、改显示名和导出模板可用。
- [ ] 搜索名称/描述/标识/标签，筛选数量与清除筛选准确；长名称提示完整。空库、无匹配、加载与读取失败分别可辨，失败可重试。
- [ ] 折叠侧栏后图标导航有明确名称，刷新恢复当前工作区偏好；其他工作区独立。资产菜单可导入/导出，新建入口直接可达。
- [ ] 检查变量后可指定类型，编辑 Schema、必填、范围、分组、默认值及数组元素。
- [ ] 对象、数组、整数、数值、字符串、布尔/null 按定义输入并生成预期文本；空值按 Schema 处理。
- [ ] 大整数切换表单/JSON 不舍入；未完成数值、超范围整数和非零数下溢不会执行成旧有效值。
- [ ] 语法提示搜索、复制、示例试跑和返回编辑草稿可用；禁用扩展有启用条件提示。
- [ ] 保存后重读一致；同一资产被外部修改时显示冲突，可比较、加载磁盘或另存副本。
- [ ] 静态引用中的模板删除被拒绝；修改显示名不破坏稳定 ID 引用。
- [ ] 保存/加载参数预设；源码、参数、无效 JSON 与未完成数值跨页/刷新恢复，多文档互不覆盖。

## 执行与结果

- [ ] 使用当前源码草稿生成；编辑输入、规格或生成方式后旧结果过期且禁用当前导出。
- [ ] 后台任务运行时可切页、查询和取消；失败/取消/中断无当前可交付产物。
- [ ] 使用模式只有参数区底部的生成按钮，编辑模式只有工具栏生成按钮；切换检查信息仍能取消任务。待生成、运行、失败/取消/中断与结果过期提示准确，不可导出原因可见。
- [ ] 成功结果可复制和实际下载，文件正文不混入诊断；下载内容与后端返回一致。
- [ ] 通用插件 JSON 无效/类型错误时阻止生成，动作切换不会继续展示可交付旧结果。

## NC 与多工序

- [ ] NC 组合显示 G 代码生成、机床配置和多工序页；模板库的 NC 模板默认使用 NC 动作。
- [ ] 新建、读取、编辑、删除机床资产，保存带指纹；错误字段、非字符串配置和非法前缀被拒绝。
- [ ] 已保存模板与临时源码入口可用；临时源码不继承上一模板 specs，源码草稿保留当前根资产约束。
- [ ] Schema/specs/defaults 同时生效，缺失机床字段、非法整数和动态引用参数越界被拒绝。
- [ ] 行号、程序号行、ASCII、空行与头注释选项符合请求；所有警告可见。
- [ ] 工序添加、复制、排序、删除、公参继承、工序覆盖与机床切换可用，行号跨工序连续。
- [ ] 某工序失败时定位工序并拒绝整个程序交付；最终 NC 非有限数值不能产生交付文件。

## 历史、插件与迁移

- [ ] 两次成功结果可以逐行比较，历史输入恢复为新草稿，成功历史产物可明确导出。
- [ ] 新记录显示环境版本；一致、已变化、旧记录信息不完整三类重执行提示准确。
- [ ] 重执行建立新记录并保留来源和实际环境比较，不改写原记录；资产改动后快照仍可重执行。
- [ ] 本地插件目录可检查/安装，依赖与配置错误阻止保存；安装不自动启用，设置区分当前和下次启动。
- [ ] 重启后 Python 报告插件可调用模板服务；卸载运行中插件被阻止。
- [ ] 实际下载资产包，在新工作区预检查并导入，模板引用/元数据/预设/机床完整恢复。
- [ ] 重复导入不覆盖，集合提供方缺失可见；后续集合失败会回滚先前新增项并报告回滚冲突。

## 布局与 HTTP 约束

- [ ] 桌面和窄屏可操作导航、表单、编辑器、对话框与下载；布局变化不丢失草稿。
- [ ] 键盘可到达主要操作，控件有明确标签，错误和状态变化清楚可见。
- [ ] 在 1280×720、1440×900、1920×1080 下无页面级横向溢出，主要操作不被遮挡；普通文字对比度至少 4.5:1、辅助文字至少 12px。编辑模式结果空状态不裁切。
- [ ] 菜单按 Esc 关闭并恢复入口焦点，点击外部可关闭；对话框 Tab/Shift+Tab 循环、Esc 关闭、关闭后焦点恢复。
- [ ] 非回环绑定失败；Host、Origin、跨站请求、Content-Type、体积与并发限制符合系统设计。
- [ ] 达到并发上限时取消入口仍可用；错误响应含明确错误信息。

本清单记录软件验收；真实控制器和工艺另按[工艺核对清单](PROCESS_CHECKLIST.md)处理。旧版验收记录见[历史清单](archive/legacy/UI_ACCEPTANCE_CHECKLIST.md)。

专项自动验收使用 `node scripts/browser_ui.cjs`，沿用 `NCTOOL_BINARY`、`NCTOOL_PLAYWRIGHT` 与 `NCTOOL_CHROMIUM` 的固定二进制/浏览器设置；脚本自建临时 home/workspace 并使用随机端口。截图、对比度检查和结果记录保存在 `target/ui-optimization/after/`；`--baseline` 仅记录优化前截图到 `before/`，需指向对应基线二进制。专项验收不替代两组既有浏览器回归或本清单的全部人工项。

## 专用车削界面与模板隐藏

- [ ] 在 1600/1440/1280/853/390px 检查左右标签、表格和程序滚动；页面无横向溢出，1600px 输入/结果并排，1280px 双通道并排，窄屏切换通道。
- [ ] 侧别/代码/轨迹/通道支持方向键、Home/End 和可见焦点；隐藏侧别与通道不能获得键盘焦点。
- [ ] 单侧修改不影响另一侧有效结果，全局修改使双方结果过期；计算另一侧保留已有预览与推荐。
- [ ] 计算预览、运行、成功、失败与过期状态明确；失败或过期不能复制、导出、加入组合。任务取消直接可见。
- [ ] 导入包含自定义文件名的 sync.left/sync.right/groove 模板资产包：通用列表、搜索、标签、计数、引用及 NC/工序选择器均隐藏，插件高级设置仍可选择。
- [ ] 普通模板即使名称或标签包含同步车字样仍显示；禁用专用插件后仍隐藏专用模板。
- [ ] 通用单文件导入专用模板时提示正确入口，不创建草稿。旧专用编辑草稿保留存储，活动标签退回普通草稿或空态；不覆盖业务会话。
- [ ] 保留旧工序与历史输入、API、资源指纹和工作区资产包导入导出；无自动迁移或静默覆盖。

- [ ] 同步粗车 ap2 留空时计算/生成自动补齐；“计算 ap2”直接回填，无需再次采用。手填值保留，无有效/不可生成推荐及晚到推荐不覆盖草稿，也不交付程序。

## 轨迹预设 UI 编辑

- [ ] 同步粗车、越程槽均可在轨迹折叠区“编辑所选预设”，加工表留空时能编辑名称、参数并保存。
- [ ] 内置轨迹必须以新 ID 另存；修改自定义预设使用读取时的指纹，外部修改后保存冲突保留编辑草稿。
- [ ] 参数为空、不完整、越界时不能保存；名称、精确参数和其他资产字段保留，两个插件的预设互不混用。
- [ ] 编辑草稿按侧别保留，切换侧别/导航/刷新可恢复；重新读取或放弃编辑明确替换/清除草稿。
- [ ] 保存引用中的预设立即使相关双方预览、确认、生成结果失效，不能复制或导出；无关一侧结果保留。本次人工调整不被预设编辑覆盖。

## 专用模板源码编辑

- [ ] 两个插件的高级设置可新建模板、编辑所选模板的完整 Jinja/NC 源码，语法校验列出引用变量，保存后实际生成消费修改后的源码。
- [ ] 自定义 ID 另存副本，原资产不被覆盖；保存保留其他元数据、Schema、默认值和读取时的指纹，冲突/失败/刷新保留源码草稿。
- [ ] 专用模板继续从通用列表、搜索、标签、计数与引用选择器隐藏；同步左右模板只在匹配侧选择，越程槽格式可由双方共用。
- [ ] 保存引用中的模板立即使相关预览、确认和生成结果失效，失败/过期不可复制、导出或加入组合；旧历史重执行继续使用冻结源码。
- [ ] 任一行模板渲染失败不交付部分文件；旧模板需明确适配并启用 v1 标记，工艺不匹配仍拒绝。
- [ ] 1280px/390px 编辑器不产生页面横向溢出，源码支持键盘编辑；结果与编辑器注明轨迹图不包含模板额外运动代码。
