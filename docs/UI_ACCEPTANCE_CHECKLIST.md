# WebUI 验收清单

适用于 NCtool 2.3.0 工作台（未发布）。以下是待执行清单，不沿用旧版 37/37 通过结论。操作说明见[WebUI 指南](WEBUI_USER_GUIDE.md)，自动检查见[贡献指南](CONTRIBUTING.md)。

2026-10-23 新版按[直接重写说明](UI_REWRITE.md)验收：桌面使用库提供的分栏，窄屏使用标签切换；生成按钮统一在工具栏；浏览器仅恢复新版命名空间，不迁移旧状态。下方涉及旧侧栏折叠、旧菜单布局和配置迁移的条目不属于本次前端重写操作；统一自动门禁为 `node scripts/browser_acceptance.cjs`，运行当前主流程、参数/math、插件三组脚本；旧命令仅为对应新版脚本的别名。不能引用旧界面的历史通过结果。

## 准备与记录

记录日期、平台、浏览器/版本、源码提交及未提交改动、CLI/插件版本、构建组合、实际执行项和证据路径。使用独立临时 home/workspace，按快速开始生成资源并编译宿主；启动默认 `template` + `parameters` 组合，必要时另起 `--features math` 构建验证数学扩展，默认地址 `http://127.0.0.1:8788`。

准备一个含对象、数组、数值、布尔和默认值的普通模板、一个可被引用的共享模板，以及一个共享参数定义/预置；可参考[模板编写指南](TEMPLATE_WRITING_GUIDE.md)和[现有示例](../examples/v2)。不使用用户的实际生产资产。

## 通用模板工作台

- [ ] 默认组合只有通用模板与共享参数能力，无 NC/机床/工序导航；带旧加工元数据的模板被拒绝，不降级为普通渲染。
- [ ] 新建、导入 `.j2` / JSON、搜索、打开多文档、复制、改显示名和导出模板可用。
- [ ] 搜索名称/描述/标识/标签，筛选数量与清除筛选准确；长名称提示完整。空库、无匹配、加载与读取失败分别可辨，失败可重试。
- [ ] 折叠侧栏后图标导航有明确名称，刷新恢复当前工作区偏好；其他工作区独立。资产菜单可导入/导出，新建入口直接可达。
- [ ] 检查变量后可指定类型，编辑 Schema、必填、范围、分组、默认值及数组元素。
- [ ] 对象、数组、整数、数值、字符串、布尔/null 按定义输入并生成预期文本；空值按 Schema 处理。
- [ ] 大整数切换表单/JSON 不舍入；未完成数值、超范围整数和非零数下溢不会执行成旧有效值。
- [ ] 语法提示搜索、复制、示例试跑和返回编辑草稿可用；禁用扩展有启用条件提示。
- [ ] 保存后重读一致；同一资产被外部修改时显示冲突，可比较、加载磁盘或另存副本。
- [ ] 静态引用中的模板删除被拒绝；修改显示名不破坏稳定 ID 引用。
- [ ] 保存/加载参数预设；源码、参数、无效 JSON 与未完成数值跨页/刷新恢复，多文档互不覆盖。

## 执行与结果

- [ ] 使用当前源码草稿生成；编辑输入、规格或生成方式后旧结果过期且禁用当前导出。
- [ ] 后台任务运行时可切页、查询和取消；失败/取消/中断无当前可交付产物。
- [ ] 使用模式只有参数区底部的生成按钮，编辑模式只有工具栏生成按钮；切换检查信息仍能取消任务。待生成、运行、失败/取消/中断与结果过期提示准确，不可导出原因可见。
- [ ] 成功结果可复制和实际下载，文件正文不混入诊断；下载内容与后端返回一致。
- [ ] 通用插件 JSON 无效/类型错误时阻止生成，动作切换不会继续展示可交付旧结果。

## 退役边界与数学扩展

- [ ] 默认构建未以 `--features math` 编译时，启用 `math` 报错；未显式选择 `extensions:["math"]` 时不注册任何数学过滤器。
- [ ] 显式编译、配置 `enabled` 启用并在请求 `extensions` 选择后，数学过滤器可用，扩展选择进入记录并可重放。
- [ ] 旧 `nc` profile 以 `invalid_profile` 拒绝；`nctool config check` 只读预检、`nctool config migrate --expected <指纹>` 显式备份并以原子写入迁移，启动不自动改写配置。
- [ ] 带旧加工元数据（`metadata.nc` 或加工 `execution.action`）的模板被拒绝，不降级为普通/受管渲染；经 include/import/extends 实际加载的冻结来源同样被检查。
- [ ] 旧加工历史只可查看、比较和导出原成功产物，不能重跑或恢复为可执行文档；原历史文件不被改写。
- [ ] 导入包含退役加工集合的资产包在预检查阶段整体拒绝，不写入任何通用资产；纯通用包正常导入并保留冲突/回滚语义。
- [ ] 退役内置 ID（`nc`、`nc-parameters`、`nc-managed`、`sync-turning`、`undercut`、`process`、`process-parameters`）不能被同名外部插件接管恢复旧执行身份。

## 历史、插件与迁移

- [ ] 两次成功结果可以逐行比较，历史输入恢复为新草稿，成功历史产物可明确导出。
- [ ] 新记录显示环境版本；一致、已变化、旧记录信息不完整三类重执行提示准确。
- [ ] 重执行建立新记录并保留来源和实际环境比较，不改写原记录；资产改动后快照仍可重执行。
- [ ] 本地插件目录可检查/安装，依赖与配置错误阻止保存；安装不自动启用，设置区分当前和下次启动。
- [ ] 重启后 Python 报告插件可调用模板服务；卸载运行中插件被阻止。
- [ ] 实际下载资产包，在新工作区预检查并导入，模板引用/元数据/预设完整恢复。
- [ ] 重复导入不覆盖，集合提供方缺失可见；后续集合失败会回滚先前新增项并报告回滚冲突。

## 布局与 HTTP 约束

- [ ] 桌面和窄屏可操作导航、表单、编辑器、对话框与下载；布局变化不丢失草稿。
- [ ] 键盘可到达主要操作，控件有明确标签，错误和状态变化清楚可见。
- [ ] 在 1280×720、1440×900、1920×1080 下无页面级横向溢出，主要操作不被遮挡；普通文字对比度至少 4.5:1、辅助文字至少 12px。编辑模式结果空状态不裁切。
- [ ] 菜单按 Esc 关闭并恢复入口焦点，点击外部可关闭；对话框 Tab/Shift+Tab 循环、Esc 关闭、关闭后焦点恢复。
- [ ] 非回环绑定失败；Host、Origin、跨站请求、Content-Type、体积与并发限制符合系统设计。
- [ ] 达到并发上限时取消入口仍可用；错误响应含明确错误信息。

本清单记录软件验收；内置加工能力已退出，不再提供工艺签收，投产前仍应由使用方自行核对模板与输出。旧版验收记录见[历史清单](archive/legacy/UI_ACCEPTANCE_CHECKLIST.md)。

自动浏览器验收沿用 `NCTOOL_BINARY`、`NCTOOL_PLAYWRIGHT` 与 `NCTOOL_CHROMIUM` 的固定二进制/浏览器设置，运行 `node scripts/browser_v2.cjs`、`node scripts/browser_review_fixes.cjs` 与 `node scripts/browser_generic_parameters.cjs`；脚本自建临时 home/workspace 并使用随机端口，报告与截图保存在脚本实际输出位置。专项验收不替代本清单的全部人工项，也不替代三平台 CI。

## 已移除的专用界面

以下能力已退出当前实现，仅保留必要的拒绝与只读兼容验证，不再作为正向验收项：

- [ ] 同步粗车、越程槽、轨迹预设与专用模板编辑器的页面、入口、懒加载 chunk、表单分支与设置项均已移除，不再出现在导航或侧栏。
- [ ] 曾由专用插件贡献的模板不再显示在通用模板列表、计数、搜索或引用选择器，也不能经插件高级设置新建或编辑。
- [ ] 通用单文件导入曾属专用模板的文件时给出正确提示，不创建草稿；旧专用编辑草稿保留在工作区存储中，但不进入活动标签页，也不覆盖当前通用草稿。
- [ ] 旧专用模板资产、历史输入与工作区资产包指纹保留，无自动迁移或静默覆盖；其历史重执行使用冻结源码且仍受当前拒绝边界约束。
