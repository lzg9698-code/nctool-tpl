# NCtool 2.3.0-preview.1 预览说明

日期：2026-10-20；平台：Windows 11；基线：`599fbda` 加本轮未提交改动。

## 预览范围

- 参数改为每个模板自己管理：编辑页一处“参数”区维护名称、类型和默认值；使用页填写本次值并支持恢复默认值。
- 删除内置共享参数插件、共享定义/预置/绑定资产和 `template.render.managed`。
- 默认运行组合为 `template`，`math` 仍为唯一可选扩展，需显式编译、启用并选择。

## 与 2.2 的破坏性差异

| 能力 | 2.2 | 2.3 预览版 |
| --- | --- | --- |
| 参数定义 | 模板内 `schema`，可另建共享定义 | 仅模板内 `schema` |
| 参数值 | 定义默认 → 模板默认 → 共享预置 → 本次输入 | 模板 `defaults` → 本次 `context` |
| 共享绑定/预置 | 参数管理页与共享绑定面板 | 已删除 |
| 受管渲染 | `template.render.managed` | 已删除，普通 `template.render` |
| 历史 | 普通与受管模板可恢复 | 普通模板可恢复；旧受管记录不再执行 |

旧共享资产文件仍留在工作区磁盘上，但新版本不读取；继续使用请保留 `v2.2.0` 二进制。普通模板资产、`schema`/`defaults`、普通模板历史不受影响。

## 验证证据

- 前端 22 文件 128 项测试与 TypeScript 检查通过。
- Rust workspace 全目标全 feature 测试、doctests、Clippy `-D warnings`、fmt、Rust 1.89 MSRV 通过。
- Python `scripts/tests` 55 项与 `scripts/check_v2.py` 通过；架构检查断言参数插件不在 workspace、CLI 依赖或生产构建树。
- 三组浏览器回归在删除插件后的最终二进制上通过：模板参数与 math、失败/恢复边界、主流程与资产包。
- 依赖审计 cargo/npm 通过，锁文件除版本外无变化。

## 已知限制

- 仅 Windows 本机完成上述验证；macOS/Linux 实机冒烟未执行，跨平台结论以 CI 为准。
- 预览版未触发远端 CI，尚未产生三平台产物；本文不声称已发布。
- 旧共享资产不提供自动迁移或转换工具。
- SHA-256 仅用于完整性校验，不表示发布者身份认证。
