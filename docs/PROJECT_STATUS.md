## 当前产品范围

默认组合为 **通用模板 + 共享参数**，保留通用插件 SDK/运行时和外部进程协议；`math` 为唯一可选 feature。CLI/WebUI 为 2.3.0，核心组件为 2.0.0，外部协议和版本化服务使用各自版本。

NC 生成、机床、加工参数、刀具/材料/标准、工艺计算、后处理/行号、同步粗车、越程槽、轨迹预设、多工序/加工组合及其专用编辑器，已从活动源码、依赖、动作/服务、配置入口、示例、资源与发行范围移除。旧 Tauri GUI 已移除，当前界面为本地浏览器 WebUI。

## 当前限制与兼容边界

- 共享定义/预置在参数管理页编辑；模板编辑页已有共享绑定面板。新增绑定仍需作者填写 JSON Pointer 并选择已保存定义，不自动推断字段含义或创建共享定义；绑定改动随模板保存。入门示例入口在模板库为空的欢迎页显示，预览/校验不写资产，确认后整包保存。
- 历史恢复到编辑文档仅支持 `template.render` 和 `template.render.managed`，不是任意插件动作的通用恢复器。历史检索、分页和清理仍待按实际规模完善；输出比较有 2 MiB 输入限制和超时保护。
- 草稿依赖浏览器 localStorage 的容量与可用性。活动 `App.tsx` 与主样式仍集中较多职责，后续拆分需保留状态所有权与异步版本守卫。
- 静态模板引用分析只枚举字符串字面量；动态引用在渲染期加载。MiniJinja 兼容范围不等于完整 Python Jinja 等价；JSON 小数/指数使用有限 f64，不提供任意精度小数。
- 插件安装来源是服务所在机器的本地目录，配置下次启动生效；外部进程隔离不是操作系统沙箱。历史环境比较不保证外部副作用或输出字节级重现。资产包回滚可能遇到并发冲突，不是跨插件数据库事务；包指纹不提供来源认证。
- 旧加工模板（`metadata.nc` 包括 null，或加工 `execution.action`）与经 include/import/extends 实际加载的冻结来源不得降级为普通/受管渲染。
- 旧加工历史只读：可查看、比较和导出原成功产物，不能重跑、试跑或恢复为可执行文档；不改写原历史，用户资产与草稿不因退役而删除。
- 退役插件 ID 与动作/服务命名空间拒绝接管。旧 `nc` profile 以 `invalid_profile` 拒绝启动；配置迁移采用只读预检、显式指纹确认、备份和原子写入，启动不自动改写配置。

- 修复结构化表单整体失效的缺陷（`patchAsset` 形参遮蔽外层 `patch`），补表单路径回归；修复标量类型切换残留 `required`、以及 `raw: undefined` 被草稿编码成存在的键。

**`browser_review_fixes.cjs` 偶发失败已定位**：失败断言读取的是 CodeMirror 的可见文本，而非 localStorage 草稿。仪器化重复运行 6 次捕获 2 次失败，两次均为切页返回后 `<details>` 已处于展开状态、脚本仍无条件点击 summary，把它**收起**，因此 `innerText()` 返回空串；同一时刻 localStorage 中的原始草稿完整存在。插件页的 `<details>` 展开状态在页面重挂后不保证回到默认关闭，这是原生 `<details>` 的浏览器行为，不是草稿丢失。

修复方式：新增幂等的 `openDetails` 辅助函数，仅当折叠区关闭时才点击；断言前等待 CodeMirror 实际渲染出预期文本。原断言保持不变，未放宽。修复后连续 6 次全部通过，主流程与共享参数两组回归亦通过。
