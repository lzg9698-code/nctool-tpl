## 当前限制

- 插件配置、安装和启停在下一次启动生效，没有热替换、插件市场、第三方前端脚本或外部表达式过滤器。
- 多工序为顺序编排，没有通用 DAG；整体交付不能撤回插件已经产生的外部副作用。
- 外部插件没有操作系统级沙箱；工作区包指纹不是签名，不提供来源认证。
- 资产包不迁移宿主启动配置、浏览器草稿或运行历史，导入拒绝同名冲突，不自动改名。
- JSON 小数/指数使用有限 f64，不支持任意精度小数；NC 整数参数为 i64，对象/null 属于通用模板而非 NC 参数能力。
- 历史环境检查追踪声明版本和服务绑定，不固定插件配置或操作系统；受管生成另行冻结参数、模板、机床及计算上下文，一致提示仍不代表设备签收。
- 默认工作区不自动装入业务模板和真实机床方案；V3 模板作为独立可导入资产包提供，仍需核对缺失刀具事实并完成工艺审核。
