# NCtool 2.0 升级状态

实现已切换为通用模板平台与可选领域插件。旧业务模板、内置机床方案和原 nctool-core/CLI 路径不再参与构建；GUI 保留旧版目录并退出 workspace。

已实现：独立 Jinja 引擎、通用 JSON 资产及乐观锁、版本化 SDK、依赖驱动生命周期、可撤销注册与观测事件、可配置服务提供方、外部进程插件、CLI/HTTP 统一动作、能力驱动 WebUI、NC 参数算法与格式化、多工序整体交付、Python 非加工示例。

首版边界：配置修改在下一次启动生效；没有热替换、插件市场、外部表达式过滤器、第三方前端脚本、通用 DAG 或操作系统沙箱。多工序事务语义只保证宿主最终产物交付，不能撤回插件自行写出的外部副作用。

验证命令、浏览器验收和跨平台检查见 CONTRIBUTING.md；本机执行证据由最终交付结果报告，CI 矩阵配置不等于三个系统已经实际验证。新 NC 示例只验证软件行为，不宣称可直接用于真实机床。

此次升级前的本地源码归档、补丁和状态记录保存在 `.nctool-backups/2026-10-01-v2/`，包含升级前已有的未提交文件；该目录不随源码包分发。

其他旧版文档属于历史参考，2.0 入口以 README、ARCHITECTURE、SYSTEM_DESIGN 和 PLUGIN_PROTOCOL 为准。
