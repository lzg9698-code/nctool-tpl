# WebUI 使用指南

适用于 NCtool 2.2 CLI/WebUI。构建步骤见[快速开始](../README.md#快速开始)，配置与接口详见[系统设计](SYSTEM_DESIGN.md)。

## 启动与工作区

运行 `nctool ui` 后访问 `http://127.0.0.1:8788`。服务仅绑定回环地址。源码运行使用 `cargo run -p nctool-cli -- ui`；首次构建须先安装前端依赖并生成嵌入资源。

`--workspace` 指定模板、预设、机床和任务记录所在目录；`--home` 指定插件与宿主配置目录。例如：

```bash
nctool --workspace ./my-workspace --home ./my-config ui
```

默认配置加载通用模板插件。完整构建执行 `nctool --profile nc ui` 才加载 NC、数学与多工序组合；保存配置也可控制启用项。模板库为空时先新建或导入模板，当前发行包不附带旧业务模板。

桌面侧栏分为页面导航、模板列表和管理入口。顶部按钮可折叠为图标导航，折叠偏好按工作区保存；展开后可搜索名称、描述、标识或标签，查看匹配数量并清除筛选。长模板名悬停可查看完整内容，列表读取失败时可重新读取。

## 使用模板与生成

1. 在“模板库”搜索名称或标签并打开模板，选择“使用模板”。
2. 通过表单填写参数，或加载已保存的参数预设。对象和数组可以递归编辑；数值尚未填写完整时不能执行。
3. 确认“生成方式”。“普通文本”使用通用渲染；“NC 程序”执行领域校验、机床联动和后处理。模板声明的能力不可用时，先启用所需插件并重启。
4. 点击“生成文件”并检查诊断和结果。使用模式的生成按钮在参数区底部，编辑模式在顶部工具栏，也可按 `Ctrl+Enter`。任务在后台执行，可以切页；结果区顶部的取消入口在正文和检查信息标签下均可用。成功后可复制或下载正文。

编辑输入、规格或生成方式会让原结果过期，过期结果不能作为当前结果导出。失败、取消或中断的任务没有当前可交付产物。历史页可以明确导出已成功的历史产物。

结果区同时显示任务状态与结果是否过期，并在导出操作上方解释不可导出的原因。工作台名称、保存状态及保存操作位于第一行，使用/编辑切换和生成方式位于第二行。操作菜单可按 `Esc` 关闭；对话框支持 `Tab` / `Shift+Tab` 循环、`Esc` 关闭及关闭后恢复焦点。

普通模板支持对象、数组、字符串、数值、布尔与 null。大整数在表单与 JSON 间切换时保留字面量；这不表示任意精度小数，后端会拒绝超范围整数和非零数下溢。错误 JSON 必须修正后才能生成，页面不会执行上一份有效 JSON。

## 编辑与管理模板

选择“编辑模板”可修改源码、参数定义、默认值及元数据。源码编辑器提供行号和语法高亮。“检查变量”识别字段后，还需要作者选择具体参数类型；自动识别不能确定字段的业务范围、单位和含义。

参数定义可设置必填、分组、对象属性、数组元素、默认值、单位和数值范围。定义方法与资产示例见[模板编写指南](TEMPLATE_WRITING_GUIDE.md)。生成使用当前源码草稿，未保存的改动也会进入当次执行。

“语法提示”可从导航或源码栏打开，支持分类、搜索、复制片段与示例试跑。扩展示例标明插件条件；返回编辑页保留草稿。

模板菜单支持复制、删除、导入 `.j2` / 模板 JSON，以及导出模板。普通模板导入先成为草稿，保存后进入模板库。专用车削模板通过工作区资产包导入，也可在插件“高级设置 · 模板格式”中新建并编辑完整 Jinja/NC 源码；通用单文件导入会给出提示。旧专用模板编辑草稿保留存储，但不出现在通用标签页。显示名称可以修改，内部资产 ID 和既有 include 引用保持稳定；仍被其他模板静态引用的模板不能直接删除。

## 保存、冲突和草稿

保存携带读取时的版本指纹。若磁盘文件被另一个窗口或工具修改，工作台显示冲突，可比较差异、加载磁盘版本或另存副本。加载前确认当前草稿是否需要保留。

源码、参数、原始 JSON 和未完成数值按工作区恢复，多文档互不覆盖。浏览器草稿是本地编辑恢复机制；迁移或备份已保存资产时使用工作区导出，不能把草稿恢复当作完整资产备份。

预设保存的是参数，便于同一模板反复使用；修改模板定义后仍应核对预设与新规格是否匹配。

## NC、机床与多工序

启用 NC 组合后出现 G 代码生成、机床配置和多工序页面。机床列表展示已保存资产，可新建、读取、编辑和删除配置。没有指定机床时，NC 动作使用虚拟示例机床及后处理默认值，不代表目标设备。配置方法见[机床配置指南](MACHINE_CONFIG_GUIDE.md)。

G 代码生成页可选择已保存模板或临时源码，设置参数、机床、行号和输出选项。模板库中其他带 NC 元数据的模板也可直接使用 NC 生成方式。同步粗车与越程槽请从侧栏进入[专用插件页面](SPECIALIZED_TURNING_PLUGINS.md)，通过左右标签切换；对应模板仅在插件高级设置中选择，不显示在通用模板列表、计数、搜索或引用选择器。临时源码需要自己的参数，不沿用先前选中模板的领域规格。

多工序页支持添加、复制、排序和删除工序。公共参数、机床和选项供工序继承，工序设置覆盖对应公共值；行号游标由宿主按实际末行号续传。任一工序失败时检查失败位置，整个程序不交付。正式使用前按[工艺核对清单](PROCESS_CHECKLIST.md)复核输出。

## 插件与设置

从本地目录检查并安装插件，检查结果包含声明、动作与依赖。安装不会启动代码或自动启用；在设置中编辑启停草稿、插件配置及服务提供方，预检查通过后保存。

界面分别显示当前运行状态和下次启动配置。修改后重启 WebUI，新的 CLI 调用在下次启动时读取配置。外部插件默认通过 Schema 表单使用；内置专用页面由插件贡献注册。详细示例见[项目 README 的外部插件章节](../README.md#外部插件)。

## 执行记录

在历史页选择记录，可查看实际输入、插件信息、诊断与产物，比较两次成功结果的逐行差异，恢复输入为新草稿，或重新执行为新任务。

重执行前显示环境“已记录版本一致”“已变化”或“信息不完整”，并列出宿主、插件和服务绑定差异。后端在实际重执行时重新检查，记录来源 ID，不改写原记录。旧记录仍可读取和重执行，但信息可能不完整。

通用模板记录源码集合快照；内置 NC/工序记录还包含机床、规格和生成选项。记录不固定插件程序、配置或操作系统，同版本一致不保证生成结果逐字相同。

## 工作区迁移

在侧栏底部打开“工作区资产”，选择“导出工作区资产”得到当前启用插件贡献的资产包，包含模板、引用、规格、默认值、元数据、预设和启用 NC 时的机床。运行历史、浏览器草稿和宿主启动配置不在资产包中。

在目标工作区的“工作区资产”菜单选择“导入工作区资产”及文件，先查看集合、稳定标识映射及冲突，预检查通过后确认导入。已有同名资产不会覆盖，也不会自动改名；缺少集合提供方时先启用所需插件。导入失败时宿主尝试反向回滚本次新增资产，回滚冲突会明确报告。

导入后检查模板引用、生成方式与机床配置，再运行代表性输入。迁移 NC 资产后仍须单独核对目标控制器与工艺条件。
