# WebUI 使用指南

适用于 NCtool 2.3.0 CLI/WebUI（2026-10-24 发布）。构建步骤见[快速开始](../README.md#快速开始)，配置与接口详见[系统设计](SYSTEM_DESIGN.md)。

当前前端于 2026-10-23 直接重写，采用完整组件库。新版不读取或迁移旧浏览器草稿和布局偏好；已保存资产通过现有 API 正常访问，启动不转换或搬运任何资源。架构与本轮验证入口见 [重写说明](UI_REWRITE.md)。

## 启动与工作区

运行 `nctool ui` 后访问 `http://127.0.0.1:8788`。服务仅绑定回环地址。源码运行使用 `cargo run -p nctool-cli -- ui`；首次构建须先安装前端依赖并生成嵌入资源。

`--workspace` 指定模板、预设和任务记录所在目录；`--home` 指定插件与宿主配置目录。例如：

```bash
nctool --workspace ./my-workspace --home ./my-config ui
```

默认配置加载通用模板与共享参数插件。数学扩展需以 `--features math` 构建（完整二进制已包含），在 `home/config.json` 的 `enabled` 中启用，并在每次渲染请求的 `extensions` 中显式选择；`--profile` 仅支持 `template`，旧 `nc` profile 会以 `invalid_profile` 拒绝，请先运行 `nctool config check` / `nctool config migrate --expected <指纹>`。模板库为空时可在欢迎页选择“查看入门示例”，预览普通文本或共享参数示例，校验后点击“确认保存整个示例”。预览和校验不写入资产；确认保存采用新标识，不覆盖已有资产。保存后从模板库打开并生成，也可自行新建或导入模板。当前发行包不附带旧业务模板。

桌面侧栏包含页面导航、模板列表和导入入口，可按名称、描述、标识或标签筛选。宽度不足 1100px 时，导航进入抽屉，输入与结果改为标签切换。长模板名悬停可查看完整内容，列表读取失败时可重试。

## 使用模板与生成

1. 在“模板库”搜索名称或标签并打开模板，选择“使用模板”。
2. 通过表单填写参数，或加载已保存的参数预设。对象和数组可以递归编辑；数值尚未填写完整时不能执行。
3. 确认“生成方式”。工作台使用当前源码草稿执行；带旧加工元数据（`metadata.nc` 或加工 `execution.action`）的模板会被拒绝，不会降级为普通渲染。插件声明的能力不可用时，先启用所需插件并重启。
4. 点击“生成文件”并检查诊断和结果。使用模式的生成按钮在参数区底部，编辑模式在顶部工具栏，也可按 `Ctrl+Enter`。任务在后台执行，可以切页；结果区顶部的取消入口在正文和检查信息标签下均可用。成功后可复制或下载正文。

编辑输入、规格或生成方式会让原结果过期，过期结果不能作为当前结果导出。失败、取消或中断的任务没有当前可交付产物。历史页可以明确导出已成功的历史产物。

结果区显示任务状态和不可导出的原因。工作台名称与保存操作位于第一行，使用/编辑切换、生成方式和唯一生成按钮位于第二行。对话框和选择控件使用 Ant Design 的键盘与焦点交互。

普通模板支持对象、数组、字符串、数值、布尔与 null。大整数在表单与 JSON 间切换时保留字面量；这不表示任意精度小数，后端会拒绝超范围整数和非零数下溢。错误 JSON 必须修正后才能生成，页面不会执行上一份有效 JSON。

## 编辑与管理模板

选择“编辑模板”可修改源码、参数定义、默认值及元数据。源码编辑器提供行号和语法高亮。“检查变量”识别字段后，还需要作者选择具体参数类型；自动识别不能确定字段的业务范围、单位和含义。

参数定义可设置必填、分组、对象属性、数组元素、默认值、单位和数值范围。定义方法与资产示例见[模板编写指南](TEMPLATE_WRITING_GUIDE.md)。生成使用当前源码草稿，未保存的改动也会进入当次执行。

“共享绑定”在编辑模式右侧，分为模板默认共享预置、当前绑定、新增绑定和识别与检查四个部分。定义与预置本身在“参数管理”页维护；绑定只决定模板里的哪个路径使用哪个共享定义。新填写的绑定需点击“添加绑定”才进入模板草稿。“检查共享绑定”解析继承值和来源，反馈类型、单位、预置和取值错误，不执行模板，也不保存资产；继续编辑后旧检查结果作废。修改绑定会解除从历史恢复的参数快照绑定，保留本次手动覆盖，再生成时使用当前定义。最后保存模板，绑定才写入工作区。

“语法提示”可从导航或源码栏打开，支持分类、搜索、复制片段与示例试跑。扩展示例标明插件条件；返回编辑页保留草稿。

模板菜单支持复制、删除、导入 `.j2` / 模板 JSON，以及导出模板。普通模板导入先成为草稿，保存后进入模板库。显示名称可以修改，内部资产 ID 和既有 include 引用保持稳定；仍被其他模板静态引用的模板不能直接删除。

## 保存、冲突和草稿

保存携带读取时的版本指纹。若磁盘文件被另一个窗口或工具修改，工作台显示冲突，可比较差异、加载磁盘版本或另存副本。加载前确认当前草稿是否需要保留。

仅新版产生的源码、参数、原始 JSON 和未完成数值按工作区恢复，多文档互不覆盖；旧 UI 浏览器存储保持原样，不会被自动加载、迁移或清理。存储失败会明确提示，请及时保存资产。浏览器草稿不能代替工作区资产备份。

预设保存的是参数，便于同一模板反复使用；修改模板定义后仍应核对预设与新规格是否匹配。

## 维护共享定义与预置

“参数管理”页创建和维护共享定义与共享预置。左侧按当前资产类型列出资产，可搜索名称或标识；右侧是结构化编辑区。定义可填写显示名称、类型、单位、分组、说明、取值范围和默认值，其中标识在保存后作为文件名保持不变。预置按定义标识填写取值，未填写的定义不会被覆盖；定义已被删除时，已填写的值仍会保留并标注来源不存在。

编辑区下方的“高级 JSON”直接编辑完整资产，表单与 JSON 表示同一份内容。保存携带读取时的版本指纹，冲突时保留草稿；未保存的编辑按工作区保留。定义和预置的字段含义与资产示例见[参数指南](PARAMETER_MANAGEMENT.md)，与模板参数定义的区别见[模板编写指南](TEMPLATE_WRITING_GUIDE.md)。

## 已移除的领域能力

当前版本已移除内置 NC、机床、多工序、同步粗车、越程槽与轨迹预设，以及它们的专用页面和编辑器；默认组合为 `template` + `parameters`，数学扩展为唯一可选能力。当前能力与替代方案见[项目状态](PROJECT_STATUS.md)与[插件协议](PLUGIN_PROTOCOL.md)；原始指南保存在[历史归档](archive/README.md)。

带旧加工元数据（`metadata.nc` 或加工 `execution.action`）的模板不会被降级为普通渲染；旧加工历史只可查看、比较和导出原产物，不能重跑或恢复为可执行文档。包含退役加工集合的资产包在预检查阶段整体拒绝，不做部分导入。

## 插件与设置

从本地目录检查并安装插件，检查结果包含声明、动作与依赖。安装不会启动代码或自动启用；在设置中编辑启停草稿、插件配置及服务提供方，预检查通过后保存。

界面分别显示当前运行状态和下次启动配置。修改后重启 WebUI，新的 CLI 调用在下次启动时读取配置。外部插件默认通过 Schema 表单使用；内置专用页面由插件贡献注册。详细示例见[项目 README 的外部插件章节](../README.md#外部插件)。

## 执行记录

历史页可按标题、记录标识或动作关键词搜索，并按状态筛选；每页 25 条，支持上一页/下一页，查询范围不限于最近 100 条。选择记录后可查看实际输入、插件信息、诊断与产物，检索成功记录作为比较基准，恢复输入为新草稿，或重新执行为新任务。

已结束的记录可在明确确认后逐条删除，删除内容包括该记录保存的输入和产物，不能恢复；正在排队或运行的任务不能删除，后端同时使用任务控制与文件锁保护。删除历史不等于删除模板资产。分页期间其他窗口新增/删除记录可能改变页边界，可刷新核对。

重执行前显示环境“已记录版本一致”“已变化”或“信息不完整”，并列出宿主、插件和服务绑定差异。后端在实际重执行时重新检查，记录来源 ID，不改写原记录。旧记录仍可读取和重执行，但信息可能不完整。

通用模板记录源码集合快照；受管渲染另存冻结的参数定义、预置与请求。记录不固定插件程序、配置或操作系统，同版本一致不保证生成结果逐字相同。

## 工作区迁移

在侧栏底部打开“工作区资产”，选择“导出工作区资产”得到当前启用插件贡献的资产包，包含模板、引用、规格、默认值和元数据。运行历史、浏览器草稿和宿主启动配置不在资产包中。

在目标工作区的“工作区资产”菜单选择“导入工作区资产”及文件，先查看集合、稳定标识映射及冲突，预检查通过后确认导入。已有同名资产不会覆盖，也不会自动改名；缺少集合提供方时先启用所需插件。导入失败时宿主尝试反向回滚本次新增资产，回滚冲突会明确报告。

导入后检查模板引用与生成方式，再运行代表性输入。包含退役加工集合的资产包会在预检查阶段整体拒绝，不写入任何资产。
